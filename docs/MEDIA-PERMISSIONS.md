# INSIPS media permissions

Every public image, video, logo, poster, thumbnail, and embed must have a record before it is presented as production content.

| local-product-screenshot | `apps/web/public/*.png` | Local product capture | INSIPS project | Project-generated fixture | 2026-09-20 | Descriptive screen summary | QA/local storytelling | Approved local | Local only |

## Rules

- Private evidence never appears in this manifest or public media bucket.
- Official embeds remain external and consent-aware when third-party tracking is involved.
- Downloaded assets require a reusable license or explicit written permission.
- Logos without confirmed reuse rights use a neutral typographic monogram.
- Media records include provider, canonical URL, object reference when permitted, dimensions, poster, alt text, moderation state, and publishing state.
- Replacing an asset requires updating this record and the asset manifest together.
