# INSIPS content sources

This file records public factual content used by the local seed and the review status required before production publication.

## Policy

- Real organization names and public descriptions require the organization's official website or official social account as the source.
- Do not claim partnership, customer status, onboarding, endorsement, verification, or impact outcomes.
- Every source must record retrieval date, exact URL, factual fields used, and review owner.
- A public directory disclosure must remain visible wherever the record is not an INSIPS tenant or customer.
- Generic licensed or generated cause imagery must never imply that it documents a named organization's actual work.
